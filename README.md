# Змейка

Небольшая браузерная игра «Змейка», написанная на чистых HTML, CSS и JavaScript. Игровое поле рисуется на Canvas; адаптация интерфейса рассчитана на настольные и мобильные экраны.

## Запуск

Сборка и установка зависимостей не требуются. Откройте `index.html` в современном браузере. Также можно запустить локальный HTTP-сервер из папки проекта, например:

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Управление

- **Стрелки** или **WASD** — изменить направление движения.
- На сенсорном экране проведите пальцем по игровому полю в нужную сторону.
- Нажмите **«Начать игру»**, чтобы начать; после столкновения нажмите **«Играть снова»**.

Съеденная еда приносит 10 очков и немного увеличивает скорость. Столкновение со стеной или собой завершает игру. Рекорд сохраняется в `localStorage` браузера под ключом `snakeHighScore`.

## Файлы проекта

- `index.html` — разметка игрового интерфейса и подключение ресурсов.
- `style.css` — стили, адаптивное оформление и анимации.
- `game.js` — состояние игры, управление, отрисовка и подсчёт очков.

## Технологии

HTML5 Canvas, CSS и JavaScript без сторонних библиотек.
